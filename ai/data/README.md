# CrickSense Data Directory

This directory stores the dataset and extracted features for the CrickSense project.

## Categories

- **U15**: Under-15 category
- **U19**: Under-19 category
- **General**: General/Open category

## Structure

- **raw/**: Manually collected original videos, categorized by age group.
- **landmarks/**: Generated landmark CSV files extracted from the raw videos, categorized by age group.
- **labels/**: Future ground-truth annotations and verified bowling phase labels.
