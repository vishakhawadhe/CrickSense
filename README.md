# CrickSense

AI cricket technique analysis for women. CrickSense uses MediaPipe computer vision and AI to analyze women cricketers' bowling and batting biomechanics with personalized benchmarks.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
